# VISI

> VISI keeps mold and die surfaces on one Windows desk: open the shop model, check the cavity, and leave the progressive-die splits on the same tool.

---

## Four Beats

1. **Name the tool.** Give the VISI shop model a short title before you split a surface.
2. **Pin the live cavities.** Keep current splits on VISI mold design and leave unused cores aside.
3. **Read the strip.** Open VISI progressive die before you move a station that already has a note.
4. **Check the surfaces.** Read VISI tool surfaces before you archive a cavity.
5. **Close the loop.** Clear finished splits so the next VISI visit does not start with a search.

## First Questions

**Does VISI replace every other program?**
No. VISI sits beside the toolroom list, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate VISI profile.

**Will VISI feel heavy on an older laptop?**
No. VISI is meant to stay readable during a normal tooling session.

**What should a new user try first?**
One small VISI cavity today, then the same progressive die tomorrow.

**Do tool surfaces leave the shop model?**
No. VISI tool surfaces stay on the same VISI shop model as the progressive die.

**Is VISI only for a finished mold?**
No. VISI can hold a single cavity while the rest of the toolroom stays off the board.

## Who Sits Down at VISI

- **Mold design** — cavities stay on VISI mold design.
- **Progressive die** — stations stay with VISI progressive die.
- **Tool surfaces** — splits stay on one VISI shop model.
- **Toolroom** — drafts and delivery files stay apart inside VISI.
- **Shared desk** — each VISI profile keeps its own pins.
- **Handoff** — the next person can read the VISI note without a tour.

## Field Note

VISI is easier to trust when the shop model stays smaller than the folder it came from. A named tool shows what is active, the cavity pins show what you will split today, and the closing note tells the next person which die station changed.

The same loop fits a single cavity, a short strip, or a toolroom shared by two people. Open the last VISI shop model, finish one progressive-die station, and leave fewer loose surface files than you found.

## One Real Pass

Pick a mold or die that already has a name. Open it in VISI, keep only those surfaces on the shop model, and finish one cavity or strip step you can see.
